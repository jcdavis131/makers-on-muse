How it works

One file, streamed live

The agent appends events to a single JSON file on the live-runs branch. This page polls it every few seconds and renders each beat. Thoughts are the agent's own words, lightly trimmed; tool calls and results are shown as they happened. Full protocol: docs/watch-protocol.md.
