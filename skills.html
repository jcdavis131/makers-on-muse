Agent Skills

Every skill our agents run on. A skill is a folder with a SKILL.md file in it: written instructions an agent loads when a task calls for them. The full library is below, scrubbed clean of personal details — the curated picks are up top.

This is the public library. Every skill file our agents can load, scrubbed clean — no names, accounts, or device info. Rebuilt weekly from the private library.

Submissions come in Phase 2. Using the Muse app, not Muse Code? What you can change there is a Setup.

What a SKILL.md skill is

Meta's Muse Code docs list four places skills load from:

  • Built inSkills that ship with Muse Code.
  • Your accountSkills in ~/.agents/skills, and a few other user folders the docs list.
  • A projectSkills committed to a repo under <repo>/.agents/skills/<skill-id>/SKILL.md, shared with anyone who clones it.
  • PluginsSkills that come with a plugin you turn on.

In a session you run a skill with its slash shortcut. Muse Code can also load a relevant skill on its own. The docs give these commands:

muse skills list
muse skills inspect <skill-id>
muse skills enable <skill-id> --scope project
muse skills install ./my-skill --scope user

Source: Muse Code docs: extending Muse Code. Read them for the file format; this page doesn't restate it.

Skills in the Muse app

The Muse app works differently. Meta's Help Center says its skills “are developed by Meta and are already part of Muse”, and that you can see which ones Muse used in your Activity log. So for the app, this site talks about Setups: the parts you can change yourself.

Source: Meta Help Center: how Muse works with skills

Coming in Phase 2

How sharing will work

This is the plan. It isn't built, and the details may change.

  • You share a link to a public git repo that holds the skill folder. We don't take file uploads.
  • Each skill is read before it is listed. The listing says what the skill asks the agent to do, and flags any step that sends, deletes, pays, or shares.
  • A skill is refused if it holds a key or password, hides text (such as zero-width characters), or tells the agent to fetch and follow instructions from another address.
  • Nothing installs from this site. You read the skill, then copy it into your own repo.

“A skill is a set of instructions your agent will follow, dear. Read every line before you add one.” — Mabel
