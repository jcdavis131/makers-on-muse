dev-dottie-api — Private Dev Only

Purpose

Dottie is your distilled reasoning factory. This dev API connects you 5× faster to trace→preference, factory v2 GRPO, EntropyThermostat, token-cache, and ACNE constructs without touching prod.

Security: dev-only, never public. No CORS allowlist, no Vercel preview alias, raw keys never committed, audit log append-only.

Quick start

export DUMBMODEL_DEV_API_KEY=$(cat ~/.scout/dev_key)  # dm_dev_* chmod600
bin/dm-dottie trace --limit 10     # trace→preference factory status
bin/dm-dottie acne --stats         # ACNE 17n27e constructs + token-cache
bin/dm-dottie daily --date 20260813 --n 3   # GRPO entropy step + LCG daily

First time here? Read references/setup.md before anything else.

Detail map

  • references/setup.md — read on first use, key rotation, or auth failure (install, key mgmt, bins)
  • references/usage.md — read for non-obvious usage (full trace/ACNE/daily examples)
  • references/errors.md — read when a call fails (honest 503/401/429, rate limits)
  • references/internals.md — read when you need the numbers (token-cache, LCG, PWA, GARNet, evidence)
  • bin/ — helpers auto-load the dev key; use them instead of hand-rolling protocol

Operating Rules

  • zero_deps true, allow acne:./src, stdlib only, no pip, no cloud, no ORM
  • Torch auto cuda else cpu — Hatch VM CPU, GPU node GPU via env CUDA_VISIBLE_DEVICES
  • PRIVATE+SECURE dev-only: no public CORS, no Vercel preview alias, .gitignore raw keys, audit log dev-api-audit.log
  • Timeline 7-field mandatory: nodeId,agentId,attempt,latency_ms,tokens_est,status,errorClass even no-change logged
  • Never fake promotion if gate <8.0 — honest 503
  • Preserve 3 LOCAL-GPU exempt when swarming <7 non-GPU lanes max
