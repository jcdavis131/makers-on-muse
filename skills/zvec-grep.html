zvec-grep — Local-First Hybrid Search (ripgrep + BM25 + Vector)

zg (zvec-grep) is Qwen Dev's open-source local-first search layer unifying exact regex (ripgrep), lexical BM25, and vector semantic search behind one CLI/MCP.

Install

  • Requires Node 22+. Use fnm: fnm install 22 && fnm use 22
  • npm install -g @zvec/zvec-grep
  • Verify: zg --version (binary at ~/.fnm/.../bin/zg when using fnm)

Core concepts

  • One index, four routes: hybrid (default, intent+lexical), --fts (BM25 exact terms), --vector (conceptual), --rg (exhaustive literal/regex, no index needed)
  • Index lives <root>/.zvec-grep/, auto-excludes .git, build/cache, respects gitignore
  • Incremental: zg index builds/updates; changing embedding model needs --rebuild
  • Freshness: fresh or possibly_stale
  • Default on-device embedding: local/potion-code-16m-v2 (Model2Vec static 256-dim, 8k tokens, no GPU speedup). Heavier locals: jina-embeddings-v2-base-code, embeddinggemma-300m, qwen3-embedding-0.6b. Remote Qwen endpoints gated via --allow-remote or zg auth grant.

Route selection (pick before searching)

  • --rg: exact identifiers, symbols, constant names, slugs, regex — especially long single-token ids (40+ chars, e.g. full model ids: --fts silently returns zero hits for those). Also the fallback when --fts returns nothing.
  • --fts: exact natural-language phrases ("era twins map").
  • --vector: conceptual / intent questions ("how is X computed?").
  • hybrid (default): when unsure — start here, then narrow by route.

CLI (v0.2.1 verified — 2026-09-04)

# index current repo
zg index

# hybrid search (default) — note: `zg query` prefix required in 0.2.1
zg query "how do we compute era twins map"

# BM25 only
zg query --fts "MTNN v5 champion 12966"

# vector only
zg query --vector "player similarity embedding"

# ripgrep only (no index) — managed rg via zg
zg query --rg "FAMILIES.*130"
zg query --rg -F "vector-hoops-model-engine" src

# status (no --verbose in 0.2.1; use plain status)
zg status

Note: zg "query" without query subcommand is invalid in 0.2.1. Always use zg query. --verbose is rejected by 0.2.1 — use zg status only.

MCP (for agents)

  • zg install auto-detects Codex, Claude Code, Cursor, OpenCode and wires MCP (Streamable HTTP http://127.0.0.1:7999/mcp, optional bearer auth)
  • Default agent toolset = 2 tools: zvec_grep_search (intent known, string not) and zvec_grep_rg (symbol/path/regex known)
  • Full 6-tool set via zg server --mcp-toolset full adds index create/drop/status/server status
  • Rule: agent must never silently create/rebuild/delete persistent index — keep index lifecycle CLI-owned

Integration points in this workspace (Scout harness)

  1. Scout Prime Coordinator (L0 router)
  • Phase 0 Orient: replace ad-hoc grep with zg query --vector for intent queries ("what drives Daily Court?") + zg query --rg for symbol lookup
  • Before routing, zg status to ensure fresh index
  1. Deep Researcher / Strategist
  • Orient step: zg query hybrid to pull memory lattice + culture + past launches (Launched, MTNN v5 gold)
  • Wide sweep: zg query --rg for exact identifiers (model ids, slugs, constant names — long single-token ids return zero hits on --fts); zg query --fts for exact natural-language phrases
  1. Executor / Builder
  • Pre-build: zg query --rg "slug.*vector-hoops-model-engine" to avoid duplicate artifact
  • Search existing assets: zg query --vector "embedding map 3D"
  1. Verifier / Forensic Auditor
  • Fact-check cascade: zg query --fts for claim triangulation (e.g., "v6 0.000758 vs 0.1180")
  • Source audit: zg status for freshness (no --verbose in 0.2.1)
  1. Active Tasks Board
  • Before claiming lane: zg query --rg "ACTIVE.*vector-hoops" + zg query --vector "hoops model engine work"
  • Prevent duplicate suppressions
  1. Timeline / Memory
  • Replace full timeline.jsonl scans with zg query --vector "manim video update"
  • Memory search: augment muse.memory_search with zg query --vector over ~/memory/
  1. Manim Video Pipeline
  • Search reusable patterns: zg query --vector "cam_style Okabe AAA" to ensure style compliance
  • Asset lookup: zg query --rg "ChimeraEquation"

Zero-deps guardrail

  • zg is Node-based, not Python. That's OK — authorized minimal dependency per TimesFM rule (minimal deps when building from scratch isn't reasonable)
  • Never auto-rebuild index in agent loop; CLI owns it
  • Keep stdlib-only Python for model training; zg is for search/orchestration only

Operational gotchas (verified 2026-09-24)

  • zg index with no path anchors to the enclosing git root — from a subdirectory of a large repo it indexes everything. Pass an explicit root (zg index <dir>) for scoped work.
  • zg status / zg query may print [ERROR ...] id_map.cc ... read only mode lines on stderr yet exit 0 — noisy but harmless; trust the exit code and the status: line.
  • ZVEC_GREP.ENGINE.LOCK.BUSY means another index/rebuild holds the lock — wait for it to finish instead of stacking commands.

Quick start for this repo

export PATH="$HOME/.fnm:$PATH"; eval "`$HOME/.fnm/fnm env`"
cd ~/workspace
zg index
zg query "vector hoops model engine"
