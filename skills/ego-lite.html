Chromium-based browser automation for AI agents — open pages, click, type, screenshot, and run site-tools. Use when the user needs web interaction, form filling, or exploratory QA.

ego-lite

Real browser, not pretend fetch.

What this does

ego-browser drives a real Chromium instance through ego.sendCDPMessage. Your agent runs heredoc JS with preloaded helpers — openOrReuseTab, snapshotText, click, typeText, js, cdp — all inside an isolated task space that reuses the user's login state without fighting them.

Use when you need: open website, visit URL, fill form, click button, screenshot, scrape page, login, automate, dogfood, QA.

This root skill is a thin wrapper around skills/ego-browser/SKILL.md — that file is the canonical agent-facing guide.

How to use

ego-browser nodejs <<'EOF'
const task = await useOrCreateTaskSpace('check dumbmodel.com')
await openOrReuseTab('https://dumbmodel.com', {wait:true})
cliLog(await snapshotText())
EOF

Helpers: listTaskSpaces, useOrCreateTaskSpace, openOrReuseTab, click, typeText, pressKey, snapshotText, captureScreenshot, js, cdp, waitForElement.

Learnings

skills/ego-browser/learnings/<site>/ holds reusable per-site packs (manifest + tools + browser-tools). Runs via runSiteTool.
