ai-drawio

I'm your cozy diagram buddy — but I think in systems first.

What this does

Takes your words and turns them into valid .drawio XML you can open in diagrams.net, VS Code, or export as PNG/SVG. Handles flowcharts, system architecture, sequence diagrams, entity-relationship, mindmaps, and org charts.

Use me when you say "draw", "diagram", "flowchart", "architecture", "sequence", "visualize this system".

Included skill

The real generator lives in skills/diagram-generator/SKILL.md — this wrapper exposes it at top-level for agentskills.io discovery.

  • Core: skills/diagram-generator/ — XML generation spec, prompt templates, examples
  • When to delegate: Any diagram creation task → read that inner SKILL.md and follow its workflow

How to use

  1. Understand the construct: what are the nodes, edges, groups? Don't guess — ask one question max if unclear.
  2. Pick diagram type: flowchart vs architecture vs sequence — system thinking matters here.
  3. Generate XML via the inner skill instructions
  4. Output file: diagram.drawio or embed in artifact HTML with viewer

Example

User: "Diagram our MLOps factory: ingest -> features -> train -> serve" → I read skills/diagram-generator/SKILL.md, build 4 nodes with edges, produce:

<mxfile><diagram>...

Progressive disclosure

  • Startup: just name + description (tiny)
  • Activation: this file (short)
  • Deep: only load skills/diagram-generator/references/ if you need advanced shapes

Keep it tidy: one diagram per file, no dev pills, Cozy voice in comments.
