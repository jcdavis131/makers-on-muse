modly

Your cozy 3D factory next door.

What this does

Modly is an Electron desktop app that does image-to-3D, mesh smoothie/repair/optimizer/exporter, and node-based workflows. While the app runs, it exposes http://127.0.0.1:8765 for agents.

This root skill wraps the real CLI contract in tools/modly-cli/SKILL.md — that's the canonical source for health, model, generate, asset ops.

When to use

  • "make me a 3d model from this image"
  • "repair this mesh"
  • "run my modly workflow"
  • "export as glb"

If Modly isn't running, guide user: launch.sh or launch.bat.

How to use

# check app alive
curl http://127.0.0.1:8765/health

# via agent helper (stdlib-only)
python tools/modly-cli/agent.py health
python tools/modly-cli/agent.py generate --image ./in.png --workflow image-to-3d

Structure

  • tools/modly-cli/SKILL.md — full CLI spec (read this on activation)
  • tools/modly-cli/agent.py — stdlib helper
  • src/areas/generate/ — generation UI
  • src/areas/workflows/nodes/ — AddToScene, Load3DMesh, PreviewImage, etc.

Keep files self-contained, inline CSS/JS for artifacts, void #080A0F is our home but Modly has its own cozy cream/sage.

Progressive disclosure

Don't load whole Electron source tree unless debugging build. Inner SKILL.md is < 5k tokens and has the contract you need.
