What the tags mean

A tag names what a workflow needs. Where a Meta page says so, the source is linked. Where only a third-party list does, or nothing we checked does, the tag says that too.

browser
Muse's built-in browser. Every Muse has one. Flight status, traffic, drive times and prices all go through it: no workflow here needs a flight-tracking, maps or shopping connector. (Meta research blog)
photo-upload
You add the photos to the chat yourself. No photo-library connector is needed: file upload is built in. (Meta Help Center: get started)
gmail
The Gmail connector, added under Settings > Connectors. (Meta Help Center: connectors)
google-calendar
The Google Calendar connector, also under Settings > Connectors. (Meta Help Center: connectors)
spotify
The Spotify connector. It is on a third-party list of live Muse connectors (postfa.st, updated Sep 27, 2026), not on the Help Center's list.
finances
The Finances (Plaid) connector, which reads bank data. Same third-party list, not the Help Center's. Set connectors to ask before acting.
podcast
Muse makes an audio episode. No Meta page we checked describes this, so check that your Muse can do it before you rely on it.

Need a service with no built-in connector? Muse can write a custom connector for a service that has an API or a command-line tool. See Setups.
